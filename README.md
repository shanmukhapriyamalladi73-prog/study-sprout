# Study Sprout

**Live site:** https://shanmukhapriyamalladi73-prog.github.io/study-sprout/  
**Public repository:** https://github.com/shanmukhapriyamalladi73-prog/study-sprout

A study buddy that turns class notes into a summary, flashcards, and a practice quiz. It can also copy a prompt for an AI chat if you choose. The built-in tools run in the browser; notes are not sent to an AI service.

## Use it

Open the live site, paste notes, then choose **Quick summary**, **Flashcards**, or **Practice quiz**. You can also add text files, PDFs, or PNG, JPG, and WebP images.

Study Sprout reads text PDFs directly. It uses English OCR for images and scanned PDF pages. You can add up to eight files at once, up to 25 MB each; PDFs can have up to 40 pages. The first time you use PDF or image reading, the browser downloads the reading tools from a CDN. Files are processed in your browser and are not uploaded.

Notes are saved in the same browser on the same device.

## Accessibility

Keyboard focus is visible, flashcards work with Enter or Space, and animations respect reduced-motion settings. File reading progress is announced to screen readers.

## Run locally

Open `index.html` in a browser. No install or build step is needed.

## Publishing updates

GitHub Pages publishes the site from the root of the `main` branch. Push changes to `main` to publish updates. Keep personal notes, passwords, and API keys out of this public repository.
